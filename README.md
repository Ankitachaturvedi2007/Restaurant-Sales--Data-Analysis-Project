
# Restaurant Sales Analysis Project

## Project Overview

This project focuses on analyzing restaurant sales data to understand revenue trends, product performance, customer behaviour, and business performance.

The project follows an end-to-end data analytics workflow including data cleaning, exploratory analysis, business questions, reporting, and dashboard creation.

## Tools Used

- Microsoft Excel
- Tableau
- Data Cleaning
- Data Analysis
- Data Visualization

## Project Workflow

Cleaned Dataset  
↓  
Sales Analysis using Excel  
↓  
Business Questions & Insights  
↓  
Analysis Report  
↓  
Interactive Dashboard using Tableau


## Project Files

### 1. Sales Analysis Cleaned Data
Contains the cleaned dataset prepared for analysis.

### 2. Restaurant Sales Analysis
Includes business questions, pivot tables, and analysis performed to answer key business problems.

### 3. Analysis Report
Contains project methodology, insights, and recommendations.

### 4. Dashboard
Interactive Tableau dashboard created to visualize sales performance.

## Key Insights

- Identified revenue trends across different time periods.
- Analyzed category-wise sales performance.
- Found top-performing products.
- Evaluated sales channel contribution.
- Studied customer ordering patterns.
